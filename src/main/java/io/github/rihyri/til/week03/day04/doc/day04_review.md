# Week 3 - Day 4. 회고

<br>

이번 수업에서는 텍스트만 처리하던 기존 AI API에서 한 단계 더 나아가 이미지를 함께 처리하는 멀티모달 기능을 배웠다.

처음에는 이미지 파일을 AI에게 어떻게 전달할지 몰랐는데, Spring AI의 `ChatClient`에서 text()와 media()를 함께 사용하는 것을 알고 나니 전체 흐름은 생각보다 단순했다. 특히 `MultipartFile`을 그대로 사용하는 것이 아니라 `MIME Type`과 `Resource` 형태로 전달한다는 부분은 기억해 두어야 할 것 같다.

또한 `Ollama`를 통해 LLM을 반드시 외부 API로만 사용하는 것이 아니라 로컬 환경에서도 실행할 수 있다는 것도 흥미로웠다. 직접 실습까지 하지는 않더라도 클라우드 LLM과 로컬 LLM의 차이와 각각 어떤 상황에서 사용하는지 정도는 이해해 두어야 할 것 같다.

특히 `Temperature, Top-K, Top-P`가 아직은 조금 헷갈린다. 단순히 값을 높이면 품질이 좋아지는 것이 아니라 다음 토큰의 후보를 어떤 방식으로 제한할지를 결정하는 옵션이라는 점을 기억해야겠다.

이번 수업을 통해 AI API를 단순 채팅 기능에만 사용하는 것이 아니라 이미지 분석이나 데이터 추출 같은 실제 서비스 기능으로 확장할 수 있다는 것을 알게 되었다.
