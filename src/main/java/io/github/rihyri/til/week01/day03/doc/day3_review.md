# Week 01 - Day 3. 회고

이번에는 Spring에서 객체가 어떻게 주입되는지와 JPA의 연관관계에 대해 공부했다.

처음에는 `@Autowired`를 필드에 붙이는 것과 생성자로 Repository를 전달하는 코드가 왜 같은 역할을 하는지 헷갈렸다. 두 방법 모두 Spring이 Bean을 주입해준다는 목적은 같지만, 필드 주입은 객체 생성 이후에 값을 넣고 생성자 주입은 객체를 생성하면서 필요한 값을 전달한다는 차이가 있었다.

특히 생성자 주입을 사용하면 `final`을 통해 필요한 의존성이 반드시 존재하도록 만들 수 있고, `@RequiredArgsConstructor`를 사용하면 생성자 코드까지 줄일 수 있다는 점을 알게 되었다.

JPA 연관관계엥서는 단순히 관계가 있다고 해서 모든 Entity를 양방향으로 연결할 필요는 없다는 점도 인상적이었다. 혼자 공부했을 때는 이러한 점들을 몰라 무조건 양방향 연결을 하였기 때문이다. `@OneToMany`나 `@ManyToOne`을 무조건 사용하는 것보다 `@ManyToOne`과 Repository 조회를 이용해 필요한 관계만 표현하는 방식이 코드 관리에 유리할 수 있다는 것을 배웠다.

아직 Entity 연관관계는 완전히 익숙하지 않아서, 더욱 공부해야겠다는 생각 또한 들었다.
