## 이해한 것

<br>

Spring이 단순히 웹 개발을 편하게 해주는 프레임워크라고만 생각했는데,
객체의 생성과 관리를 Spring Container가 담당한다는 점이 핵심이라는 것을 알게 되었다.

특히 직접 `new`로 객체를 생성하지 않고 Spring이 객체를 관리하고 주입해주는 IoC와 DI의 개념이 인상적이었다.
