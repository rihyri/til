# Week 4 - Day 2. 회고

<br>

이번 수업에서는 RAG의 개념을 배우고 Vector Store에서 관련 문서를 검색한 뒤 LLM에게 전달하여 답변을 생성하는 과정을 구현했다.

처음에는 Controller에 비슷해 보이는 API가 많아 각각 왜 필요한지 헷갈렸다.

코드를 다시 살펴보면서 `/search`는 Vector Store에서 문서를 검색하는 `Retreival` 단계까지만 수행하고, `/ask`는 검색된 문서를 다시 LLM에게 전달해 답변까지 생성한다는 차이를 이해할 수 있었다.
`/ask-with-source`는 여기에 참고한 문서 정보까지 반환하고, `/ask-in-document`는 Metadata Filter를 이용하여 특정 문서 안에서만 검색한다.

Service 코드에서는 각 메서드의 역할을 구분하는 것이 가장 중요했다. 처음에는 하나의 복잡한 RAG 로직처럼 보였지만 다시 정리해보니 각각 **문서 검색 → 검색 문서 결합 → LLM 답변 생성**이라는 하나의 흐름을 나누어 구현한 것이었다.

<br>

이번 실습을 통해 RAG는 단순히 LLM에게 질문하는 기능이 아니라, 어떤 문서를 검색해서 어떤 Context를 제공하느냐가 중요한 구조라는 것을 알게 되었다.
